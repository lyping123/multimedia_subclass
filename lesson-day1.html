  1. Describe the HTML document skeleton.
  2. Use common elements: headings, paragraphs, images, buttons, forms, containers.
  3. Apply attributes: class, id, type, name, placeholder, alt.
  4. Style with basic CSS: color, spacing, alignment, fonts, borders.
  5. Build & style a user input form.
  6. Attach a simple click/submit event via JavaScript.

3. Core Concepts Cheat Sheet

Skeleton: <!doctype html> → standards mode.

Block vs Inline: Block (<div>, <p>) vs inline (<span>, <a>, <img>).

Attributes: class (style hook), id (unique), name (form key), placeholder, type, alt.

CSS Rule: selector { property: value; }

Common CSS: color, background, margin, padding, border, font-size, display.

Events: click, focus, submit, mouseover. CSS pseudo-classes :hover, :focus.

4.1 Minimal HTML Page

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1" />
  <title>Day 1 Demo</title>
  <link rel="stylesheet" href="styles-demo.css" />
</head>
<body>
  <header>
    <h1>Welcome to the Aquarium Form</h1>
    <p class="intro">Today we learn HTML & CSS basics.</p>
  </header>
  <section id="info">
    <h2>About</h2>
    <p>This page collects visitor interests for future events.</p>
    <img src="image/reef.jpeg" alt="Colorful coral reef" width="300" />
  </section>
  <section id="signup" aria-label="Visitor interest form">
    <h2>Sign Up</h2>
    <form id="interestForm" action="#" method="post">
      <div class="field">
        <label for="name">Name</label>
        <input type="text" id="name" name="name" placeholder="Your full name" required />
      </div>
      <div class="field">
        <label for="email">Email</label>
        <input type="email" id="email" name="email" placeholder="you@example.com" required />
      </div>
      <div class="field">
        <label for="favorite">Favorite Exhibit</label>
        <select id="favorite" name="favorite">
          <option value="reef">Coral Reef</option>
          <option value="shark">Sharks</option>
          <option value="jellyfish">Jellyfish</option>
        </select>
      </div>
      <div class="field">
        <label for="comments">Comments</label>
        <textarea id="comments" name="comments" rows="4" placeholder="Any interests or questions..."></textarea>
      </div>
      <button type="submit" class="primary-btn">Submit</button>
    </form>
    <div id="message" class="hidden" role="alert"></div>
  </section>
  <script src="demo.js"></script>
</body>
</html>

4.3 Simple JavaScript (demo.js)

const form = document.getElementById('interestForm');
const message = document.getElementById('message');

form.addEventListener('submit', function(e){
  e.preventDefault(); // stop real submission for demo
  const name = form.name.value.trim();
  const favorite = form.favorite.value;
  if(!name){
    message.textContent = 'Please enter your name.';
    message.classList.remove('hidden');
    message.style.borderColor = '#cc3300';
    return;
  }
  message.textContent = `Thanks, ${name}! We noted your interest in ${favorite}.`; 
  message.classList.remove('hidden');
  form.reset();
});

5. Teaching Notes & Talking Points

  • Separation of concerns: HTML (structure), CSS (presentation), JS (behavior).
  • required attribute gives built‑in validation.
  • Accessibility: alt text, label/for pairing, meaningful button text.
  • Progressive enhancement: page usable without JavaScript.

6. Guided Student Activity (Core)

  1. Create day1-form.html skeleton + heading.
  2. Add purpose paragraph.
  3. Insert image with descriptive alt.
  4. Build form: name, email, select (3 options), comments, submit button.
  5. Link CSS; style background, borders, spacing.
  6. Add button hover effect.
  7. Add JS submit feedback message.

  • Use :focus-visible for keyboard focus.
  • Pulsing keyframe animation on hover.

10. Common Mistakes to Watch

MistakeFix
Forgot <!doctype html>Always include for standards mode.
Missing image altAdd descriptive text.
Using <br> for spacingUse CSS margin/padding.
Inline styles everywherePrefer external CSS file.
Not resetting formCall form.reset() after confirmation.
